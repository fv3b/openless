## 1. 浮框候选区

```
┌──────────────────────────────────┐
│ ● 语音输入中              ▁▃▅▃▁   │  状态行（现有）
│ ✓ 翻译   ✓ 状态码附注         ✕   │  命中徽标行（现有，有命中才出现）
│ ⚑ 「风险控制」最近说过 3 次 [存] ✕ │  常用语提醒条（新，命中才出现）
│ 精准词  1·灰度发布  2·功能开关     │  候选组（新：类型标签＋全局序号）
│ 表述    3·先在小范围试运行 …      │
│ 常用语  1·项目背景  2·代码规范     │  推荐行（新：独立序号）
│ ──────────────────              │
│ 指令预览（大字，主角）              │
│ 转写流（小字）                    │
└──────────────────────────────────┘
```

- **顺序**：状态行 → 命中徽标行 → 候选区 → 指令预览 → 转写流；候选区三层自上而下＝常用语提醒条 → 候选组 → 推荐行；任一行无内容整行不渲染。
- **常用语提醒条**：「「XXX」最近说过 N 次」＋[存为常用语]＋[✕ 忽略]；忽略＝此条不再提示。
- **候选组**：每组一个小类型标签（精准词／表述／命名）＋chips；chips 带全局连续序号（阿拉伯数字，如 `2·灰度发布`）；选中＝勾选高亮，再点＝取消；选中 chip 右侧出现小[存]。
- **推荐行**：标签「常用语」＋chips（独立编号），无[存]（已在库）。
- **空间策略**：候选区出现时卡片向上长高（吃窗口上方透明余量，上限接近全高）；不够时指令预览滚动兜底；转写流不动。
- **动效**：出现/消失用轻淡入＋高度过渡（传达状态变迁）；系统开启"减少动效"时直出。
- **交互载体**：浮框 focus:false 不抢键盘；全部点击走 pointerEvents:auto（沿用 ✕ 按钮先例），acceptFirstMouse。
- **加载**：无"正在看"指示（自动触发、1-2 秒出结果，闪示添噪）。
- **错误态**：assist 失败 → notice 行轻提示（复用现有），预览保持上一有效状态；新批次覆盖旧批次。
- **✕ 撤销**：命中徽标行的 ✕ 扩展为"撤销最近一次生效动作"（命中/候选选中/推荐选中统一语义）；只要存在可撤销动作即显示。

## 2. Ghostwriter 视图（主窗口新页）

- **入口**：主界面导航唯一「Ghostwriter」项（带图标；替换 M2 的「常用语」项）；移动端 MoreSheet 同步收敛为一个 Ghostwriter 入口。
- **形态**：一页三页签——常用语／任务书／设置；页签用项目分段控件惯例。
- **常用语页签**：现 GhostwriterSnippets 页内容迁入（列表、编辑抽屉、空态保持），页头并入页签。
- **任务书页签**：5 行列表（名称＋一句用途说明＋「已改」标记）；点开右侧抽屉——用途说明 → 正文编辑（textarea＋字符数）→ 折叠区「固定部分（只读）」→ 保存 ／恢复默认（需确认）／取消。
- **设置页签**：开关区（候选建议、常用语推荐）→ 节流区（两枚 ms 输入，范围 500–10000，越界即时提示）。
- **页头**：全页带「Ghostwriter」名称（kicker/title），页内可辨身份。
- **设置页入口**：现设置页 Ghostwriter 区，M2 三开关原位换一枚「Ghostwriter 设置」按钮（仅样式为 Ghostwriter 时显示）→ 直达本视图设置页签。
- **图标**：全入口同一枚（实施时从项目图标库选定，笔/羽毛类优先）；禁 emoji。
