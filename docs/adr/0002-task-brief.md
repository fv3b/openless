# 任务书机制：正文可编辑、数据注入与输出结构固定、覆写式独立存储

Ghostwriter 每个 LLM 功能对应一份「任务书」：可编辑的只有"交给 AI 的任务要求"正文；数据注入（当前内容／常用语库／重复档）与输出结构（候选／推荐的返回格式）由代码固定，界面只读可见；修改走独立文件 `ghostwriter-prompts.json`，只存覆写、缺省用代码内置默认、每份可恢复默认、保存即生效。

另一条可行路是照风格包先例全文开放（Style 页就是这么放的）。但输出结构是代码解析的契约，改坏会让整个功能失灵且难自查；"正文可编辑＋契约只读"既满足调能力的需求，又把改坏半径限制在正文语义内。若日后确需全文编辑，单开高级模式，不默认开放。
