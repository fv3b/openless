# ASR 提准与提取闭环 设计文档

日期：2026-09-18｜状态：已拍板（用户逐条裁决）｜关联：ADR 0003、dialog/design.md

## 一、真实使用面

- **候选提示**：说话中随时瞟、按自己节奏读；纯累积只进不出（会话结束清）。
- **ASR 提准**：设置配好后无感生效（二遍复核默认开、输入框偏置默认开、背景按需开）；效果＝同样说法错字变少。
- **热词提取闭环**：发现 ASR 老把某词识别错 → 词典页「从语音记录提取热词」→ 选记录（全部历史多选）→ LLM 从 **raw 原文**找疑似识别混乱的词＋建议正确写法 → 编辑确认 → 批量进词典 → 下次识别正确。
- **结束漏字**：说完立刻停不吞尾字（+300ms）。
- **浮框阶段**：按结束→看进度→粘贴即收；失败看原因手动关。
- **完成标准**：错字率可感下降；混乱词「发现→提取→进热词→下次识别正确」闭环走通；浮框消失＝粘贴完成。

## 二、机制边界（官方文档口径，2026-09-18 核实）

- **热词**＝词级准确率：同音/近音片段优先选热词写法；**不管话题范围**。
- **dialog_ctx 上下文**＝语义场景偏置（对话历史/个性化/业务场景，800 tokens/20 轮）：**缩小话题范围靠它**（最近语音已自动喂）。
- 结论：词典热词存「识别不准的词」；话题范围不归热词管。

## 三、决策记录（用户裁决）

1. **候选纯累积无淘汰**：去掉 8 条 FIFO（保留按文本去重、空批次不清、会话结束清）。
2. **二遍复核（enable_nonstream）**：做成偏好**默认开**，进设置。
3. **输入框内容偏置**：AX 可行性探针先行；可行则实现，偏好**默认开**，进设置。
4. **LLM 有边界修正**：落点＝终稿润色/对话出稿任务书纠错口径——只修同音错字与明显语义不通，**禁增删内容**；不加独立调用；测试钉边界。
5. **替换词表指引**：配置文档（火山控制台 `correct_table_id`）。
6. **dialog_ctx 加固定场景描述**：「用户在通过语音给 AI 助手下指令」（官方示例 d 类个性化信息）。
7. **热词提取**（词典页新向导）：判定信号＝**LLM 读 raw 原文**找疑似识别混乱（同音/不通/语义突兀），给建议正确写法；候选形态＝{原文错误写法, 建议热词, 例句}（例句仅确认时参考，**词典只进词不加备注**——词典 note 字段是内部学习标记，不动）；目标去向 v1 **只进词典热词**（纠正规则手动加）。
8. **提取范围统一改造**（常用语提取＋热词提取一起）：**全部历史多选**（撤 3 天窗）；**已提取过的记录样式淡化**（仅视觉提醒，不改变动作——仍可多选提取）；提取标记＝单一字段，任一提取写入。
9. **背景偏好化**：开关**默认关**＋「实验性」标注；数量 N＋单位（**条 / 天**）；会话启动按设置捕获，撤写死的 3 条。
10. **补录 300ms**（固定值，维持）；**浮框阶段显示直到粘贴**（维持）；**对话热键三态**（维持冻结——**方向锚：代笔与对话未来合并**，合并后热键歧义自消）。

## 四、机器契约

- 背景块头（代码固定）：`最近语音（次要参考，仅供理解背景，不是本次要处理的指令）：`
- 纠错口径（任务书正文措辞，测试钉边界）：「只修正明显的同音错字与语义不通处，绝不增加、删除或改写用户已说清的内容」
- dialog_ctx：`context_type:"dialog_ctx"` + `context_data[]`（最近语音文本＋固定场景描述条目）
- ASR 场景描述（代码固定）：`用户在通过语音给 AI 助手下指令，内容为待办与任务类表达`
- 提取标记：DictationSession 单一字段（任一提取写入，两个向导共用淡化样式）

## 五、边界（本轮不做）

- 纠正规则去向选项（提取 v1 只进热词）；Omni 引擎补录宽限；`reject_hotkey_collisions` 纳入对话热键；dialog_ctx 图片上下文；替换词表的自动维护
