# 语音 AI 指令台「Ghostwriter」— 设计定稿（2026-09-11 全盘重推）

## 场景与痛点

用户日常拿语音输入法**给 AI 下指令**（对话、任务指令，说出的话直接丢给 Claude/ChatGPT 处理，产出物是 AI 的回应）。三层坎：

1. **说得乱**：说话绕、没结构、口水词多，AI 理解偏差，常要追问好几轮才对上。
2. **表述不出来**：不专业，词汇储备不够，很多概念只有模糊方向和场景描述，说不出准确的词，意思本身还常有偏差；命名（功能名/项目名/文件名）想不清楚，需要 AI 给候选。
3. **背景负担**：项目背景、偏好、约束每次都要口头重复；很多相关联的信息自己也不懂、说不清。

## 愿景

你只管说。它把口语流水账整理成 AI 能一次听懂的指令；你卡词、说不清的时候它帮你说清；你调优过的好说法它帮你记住、下次随叫随到。浮框是这一切的共同面板。

## 管线与三流机制

```
热键按下 → 建 GhostwriterSession（ghostwriter 激活置 Raw 照旧）
说话中（流式 ASR partial 实时到浮框）→ GhostwriterSession::feed(delta)
  ├→ segmenter 断句
  ├→ 流1 润色流：段→指令化润色→ 润色预览流
  ├→ 流2 候选流：说不清的点→LLM 给名字（term 认出的叫法/naming 新造名）→ 浮框候选区
  ├→ 流3 推荐流：按内容推荐已存常用语（缩小范围）→ 浮框候选区
  ├→ 规则（无 LLM）：触发词命中＝纯字符串匹配，即时高亮生效
  └→ 常用语库：一套（触发词→表述文本＋种类 表述/背景）
松开 → 尾段补润（融掉还没消化掉的候选）→ assembled() 一次性贴（置 Raw 照旧）
停止 → 浮框收起
```

- **三条流独立异步、各自节流可调**（进 UserPreferences），不设硬延迟预算。流开关的行为语义：**润色流常开**（无机械模式，不设开关）——命中即时生效、段润色与材料融合照常，`assembled()` 对润色失败的段/尾回落原文；关掉候选流/推荐流只静默对应浮区，其他照常。
- **润色流（指令化）**：段边界断句；prompt 语义是**指令化**而非文风美化——去口水嗯啊、理成结构、把口语表述转成准确说法；边界＝不改你的意图。每段带已润前文，风格一致。口头挑中的候选进待融队列，由后续段润色融进去；没赶上的由尾段补润融掉。
- **候选流（知识注入通道；2026-09-16 收敛，待实施，见 ADR 0003）**：说话中检测到卡词信号（句尾停顿等），触发 LLM 找出说话里**说不清的点**（一个东西、它的部分、几样东西的关联——什么都有可能），逐点给名字：**term 认出的叫法**（业界已有本名：给本名＋白话注释「就是你说的那个X」——认得出、拦截理解偏差）与 **naming 新造名**（要新造的东西：按领域惯例起名＋理由——立得住），尽量沿用本名作词根。一个点只出一个名字，优先挑最影响理解的点（上限照旧）。候选进浮框候选区，点选或口头「用第二个」即选中，进待融队列由润色流融进文本。未选中的候选松手即丢弃，不硬塞。**分界：润色管形式（自动、无需选），候选管知识注入（用户没说的东西，需确认）**——原「候选表述」（顺句）归润色职责，已移除。
- **推荐流**：LLM 按当前内容从已启用的常用语库里挑相关的几条推荐，缩小选择范围（触发词记不全时机器替你扫）；推荐结果与现场候选同区展示，点选或口头选。
- **常用语系统（动作＋注入合一）**：一个实体 `{触发词/别名 → 文本, 种类: 表述|背景, 附带背景: [引用|手写]×N, 启用}`，一个库一个管理页。两条生效路径：**触发词命中**（纯字符串规则，即时高亮生效）＋**推荐**（LLM 挑选）。表述＝文本作为材料交给润色器融进该段、其附件进背景块；背景＝整条进背景块。背景落点是**全局设置**（Ghostwriter 设置页签），所有背景同时应用。同一背景一次会话只贴一遍。第一期只做这两条路径；AI 自动判断该附什么背景，等库养肥后做。
- **沉淀闭环**：重复说到但未配置的项目→浮框提示一键存常用语；挑中的候选→可顺手存成常用语。

## 浮框交互

560×420，说话中从上到下三区：

```
┌────────────────────────────┐
│ 候选区（卡词时浮出）＋ 命中徽标行    │
│ [术语A] [术语B] [术语C]  ✕ 取消  │
│ ────────────────────      │
│ 指令预览（大字，主角）             │
│ 「若此刻停下将贴给 AI 的完整结果」  │
│ ────────────────────      │
│ 转写流（小字，你说的原话滚动）      │
└────────────────────────────┘
```

- **候选区置顶**：含两行——现场候选（LLM 现场生成）与推荐常用语（库内挑选）；点选或口头「用候选二」/「用常用语二」选中（口头选带类别前缀消歧，点击不受影响），选中项高亮进待融队列，预览随之更新。任一行无内容即整行收起，不留白条。
- **错误态**：任一 LLM 流失败→指令预览保持上一有效状态、转写流照滚、错误在命中徽标行轻提示（不弹窗）；流失败不阻塞贴出（兜底照旧走上游原路径）。
- **指令预览居中**：润色后的当前段＋已融合材料＋命中附注块，始终显示「若此刻停下将贴给 AI 的完整结果」——所见即所贴，预览与最终拼装同源。
- **转写流沉底**：原话照滚，是上下文参照，不是主角。
- **「✕ 取消」**：撤销最近一次生效动作（候选选中/推荐选中/常用语命中/融合，统一语义）。
- **命中徽标**：常用语命中时轻提示（如「✓ 命中：翻译器」），不弹窗打断说话。
- **停止即收起**：浮框停止即收起，仅兜底 toast 短暂显示。
- **管理页一套**：常用语管理页照 Style 页模式——列表（搜索＋种类筛选＋单行条目）＋增删改＋启用开关；背景落点不逐条设置，走设置页签的全局「背景落点」；空库空态直通「新建常用语」＋一句说明常用语是干嘛的。

## 硬前提与客观地基（上游代码实证，非设计决策）

- 候选流要求「说话中实时出字」：当前默认 ASR 源（智谱）为批量、停止才出全文，需切换流式源；上游已支持火山/讯飞等流式（`asr/volcengine.rs:704` 流式 partial → `EngineProgress::TranscriptDelta` → 前端）。
- Raw 透传门控已存在（`dictation_engine.rs:484`）：ghostwriter 激活置 Raw 后松开一次性贴拼装文本、不逐字漏插入、不重润整段。
- 浮窗先例：capsule 静态窗口（无边框、`alwaysOnTop:true`、`focus:false` 不抢键盘）。
- 现成模板：`style_pack_store.rs`（存储＋管理页）、`selection_voice_intent.rs`（三层意图解析）、`prompt_compose.rs`（marker 分段）、`QaPanel.tsx`（浮窗页面）。
