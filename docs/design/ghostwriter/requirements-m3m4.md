# Ghostwriter M3/M4 需求文档（候选流·推荐流·沉淀·任务书·设置视图·历史扩展）

（2026-09-15 拷问定稿）

总背景与三流机制见同目录 `design.md`，词汇以项目根 `CONTEXT.md` 为准。本档与 `design.md` 冲突处，以本档为准——差异：不设机械模式（润色常开）、不设纯净模式快捷开关（要用纯净听写自行切换胶囊样式）。

## 一、范围与里程碑

**M3 ＝ 候选流＋推荐流＋沉淀闭环＋任务书＋Ghostwriter 视图**

1. 候选流：说话中由 LLM 自判卡词，现场生成候选（精准词／候选表述／命名三类）；候选区展示，点选或口头选即入待融队列。
2. 推荐流：同一次调用里，LLM 从已启用常用语库挑出相关的几条，与候选同区展示、选择。
3. 沉淀闭环：跨会话重复说法的自动发现（重复档）＋说话中提醒＋确认后一键入库；选中的候选可顺手存。
4. 任务书管理：五份任务书（指令化润色／候选生成／推荐挑选／沉淀提醒／沉淀抽取）可查看、编辑、恢复默认。
5. Ghostwriter 视图：新增「Ghostwriter」页【新建】＝一页三页签（常用语／任务书／设置）；主界面仅此一个入口（导航项，带名称与图标）；现设置页对应区域只留一枚「Ghostwriter 设置」按钮直达设置页签（M2 内嵌的三枚开关迁进新页，仅样式为 Ghostwriter 时显示）。
6. 节流参数生效并可调（候选／推荐各一枚，进设置页签）。

**M4 ＝ 历史扩展**

7. 历史详情：数据非空时出现「Ghostwriter 明细」按钮，点开为收起面板，展示本次命中的常用语与选中的候选。

**明确不做**：机械模式（关掉润色的行为态）；纯净模式快捷开关；多套任务书切换；全 App 提示词管理；沉淀的事后复核列表。

## 二、真实使用面

### 使用时机

- 说话中卡词、词不达意 → 候选兜你；
- 触发词记不全、想不起来库里有啥 → 推荐替你扫库；
- 同一背景／偏好／约束又要重复说 → 沉淀提醒（重复档攒过次数才会提）；
- 事后想知道某次贴出文本为什么长这样 → 历史明细；
- 觉得某功能不合口味 → 改它的任务书。

### 主流程

1. **触发**：静默 ≥1.5 秒或说完一句时，按节流发起一次实时助手（assist）调用；上一次未返回则不叠新调用。
2. **LLM 自判**：一次调用同时产出——候选（0-2 组，每组 ≤5、总 ≤8）／推荐（≤3 条）／沉淀命中（0-1 条）；没有就不出。
3. **展示**：候选区自上而下＝沉淀提醒条 → 候选组 chips（全局连续编号，chips 显示序号）→ 推荐常用语行（独立编号）；任一行无内容整行不渲染。
4. **选择**：点 chip，或说「用候选N」／「用常用语N」（N 支持中文数字与阿拉伯数字）。选中项打勾高亮、可多选；内容进待融队列。
5. **融合**：后续段润色或停止时尾段补润把待融材料自然融进文本；指令预览随之更新（与最终贴出同源）。
6. **沉淀**：assist 命中重复档某条且未入库 → 提醒条「「XXX」最近说过 N 次 · 存为常用语」；点存即入库。选中候选旁的小「存」走同一逻辑。

### 例外情况

- assist 失败或超时：notice 行轻提示，预览保持上一有效状态，不弹窗、不阻塞贴出；新批次到达覆盖旧批次。
- 无候选／无推荐／无沉淀命中：对应行不渲染，不留白条。
- 口头命令未命中（没有候选浮着、序号越界）：不剔除、当普通话保留——宁可留着也不误删；命中成功才把口令从句中整体移除（连同紧邻标点）。
- 选中未及融入：停止时尾段补润兜底；补润也失败则材料以原文追加文末——不丢用户的选择。
- 重复档为空或抽取失败：静默跳过本次，不提示、不报错。
- 候选／推荐两个开关全关：实时助手与沉淀抽取都不跑（攒了也无提醒通道）；文本照贴、命中照旧。
- 旧数据兼容：preferences.json 中已删字段忽略回落；历史老记录无新字段照读。
- 任务书被改跑偏：行为随之变化属预期；「恢复默认」一键回正。

### 完成标准

- 说卡词／说不清 → 候选按判据出现；点选或口头选 → 最终贴出文本包含该内容；
- 沉淀提醒 → 点存 → 常用语管理页可查、下次说触发词能命中；
- 任务书改动 → 下一次调用即生效；恢复默认可用；
- 历史：老库照读、新记录明细按钮条件出现、明细内容正确；
- 回归：M2 的命中／撤销／尾段补润／预览同源不破坏；`cargo test -p openless-core` 全绿、前端测试与构建过。

## 三、决策与为什么

1. **卡词判断全交 LLM，不用规则词表**：内容理解是 LLM 强项；词表脆（换说法失效、多语言维护、引用误报）。机械侧只保留"何时叫它"：停顿／句毕＋节流＋在飞跳过。
2. **候选／推荐／沉淀判断合一次调用**：分开三次＝三倍成本与延迟；合成一次后开关与节流仍独立——候选节流＝调用最短间隔，推荐节流＝推荐重算最短间隔（未到期复用上次结果）。
3. **口头命令：浮着才认、失败不剔**：误删是破坏性且不可见；留着是可见可恢复的。
4. **沉淀跨会话且确认后才存**：原始痛点即"背景每次重复"；自动存会产生垃圾库，确认成本只是一次点击。
5. **低侵入原则（本轮通用）**：宿主界面每处最多一枚入口按钮，入口统一带 Ghostwriter 名称与同一图标；自有内容集中在一个「Ghostwriter」视图（常用语／任务书／设置页签）；M2 内嵌进设置页与导航的内容迁走。
6. **用"任务书"而非"提示词编辑"**：可改的是"交给 AI 的任务要求"正文；数据注入（内容／库／重复档）与输出结构由系统固定（改坏会整体失灵）；独立存储只存覆写，恢复默认兜底。
7. **砍机械模式与纯净快捷开关**：机械模式收益窄、概念成本高；纯净听写已被样式切换天然覆盖；润色常开。
8. **节流暴露在设置视图**：给手感留调钮（默认 2000ms，范围 500–10000ms）。

## 四、机器契约（锚点）

- **任务书五份**：指令化润色／候选生成／推荐挑选／沉淀提醒／沉淀抽取；每份＝一句用途说明＋可编辑正文＋只读可见的固定部分；保存即生效；各自可恢复默认。
- **存储**：`ghostwriter-prompts.json`【新建】（只存改过的覆写，缺省＝代码内置默认）；`ghostwriter-sediment.json`【新建】（重复档：说法、次数、最近例句、已提示标记）。
- **节流**：默认 2000ms、范围 500–10000ms；候选与推荐各一枚独立。
- **候选上限**：≤2 组、每组 ≤5、总 ≤8；chips 全局连续编号；推荐行独立编号。
- **口头选字面**：「用候选N」「用常用语N」，N 支持中文数字与阿拉伯数字（二／2）；须在候选浮着时识别。
- **沉淀入库默认**：触发词由 LLM 拟、贴位默认「贴进正文」、启用；同一说法只提醒一次；每次会话至多抽 3 条。
- **Ghostwriter 视图**：新页【新建】＝页签 常用语／任务书／设置；主界面唯一入口＝导航「Ghostwriter」项（同一图标）；设置页一枚「Ghostwriter 设置」按钮直达设置页签；设置页签内容＝候选开关、推荐开关、两枚节流输入。
- **历史字段**：`DictationSession` 增两个 `#[serde(default)]` 字段（命中列表、选中候选列表）；明细按钮仅在字段非空时出现。
- **清理项（M3 一并完成）**：移除 M2 已实现的机械模式相关开关／分支／文案／测试／偏好字段；`design.md` 相应条目同步订正。
